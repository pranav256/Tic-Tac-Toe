# Tic-Tac-Toe for Android

A classic two-player Tic-Tac-Toe game developed in Java for native Android devices.

## Features

- **Turn-Based Logic:** Interactive 3x3 grid with alternating X and O player states.
- **Win Detection:** Real-time matrix evaluation checking rows, columns, and diagonals for win or draw conditions.
- **Score Counter:** Persistent match score tracking across consecutive rounds.

## Tech Stack

- Java
- Android SDK
- XML UI Components

## Build & Run

Import the repository into Android Studio and run on an emulator or physical Android phone.
